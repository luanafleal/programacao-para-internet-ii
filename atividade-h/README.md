# Atividade H — Thinking in React

## Sobre a atividade

Desenvolvimento de uma aplicação web utilizando React e TypeScript, seguindo as orientações do tutorial oficial do React: [Thinking in React](https://react.dev/learn/thinking-in-react).

O objetivo é aprender a construir interfaces utilizando componentes, organizar dados, trabalhar com estados e implementar filtros e pesquisas.

## Projeto

**Nome:** produtos-web

**Tecnologias utilizadas:**
- React
- Vite
- TypeScript
- CSS Modules

## Funcionalidades

- Exibição de produtos organizados por categoria.
- Pesquisa de produtos pelo nome.
- Filtro para exibir somente produtos disponíveis em estoque.
- Identificação visual de produtos sem estoque.

## Estrutura do projeto

O projeto está organizado em componentes, dados e tipos, buscando manter o código separado e organizado.

```text
produtos-web/
├── src/
│   ├── components/
│   ├── data/
│   ├── types/
│   ├── App.tsx
│   ├── index.css
│   └── main.tsx
├── public/
└── package.json
```

## Como executar o projeto

Entre na pasta do projeto:

```bash
cd produtos-web
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```

O Vite disponibilizará um endereço local para acessar a aplicação pelo navegador.
